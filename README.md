# AQUA LIFE - Premium Water Delivery Website

🌊 A modern, premium, dark, and cinematic website for AQUA LIFE - a premium drinking water delivery service.

## Features

✨ **Premium Design**
- Dark theme with aqua accents
- Cinematic animations and transitions
- Glassmorphism effects
- Custom cursor with glow effects
- Responsive design for all devices

🌍 **Multi-Language Support**
- Kazakh (KZ)
- Russian (RU)
- English (EN)
- Instant language switching with smooth animations
- Persistent language selection

⚡ **Performance**
- Smooth scrolling with Lenis
- GSAP animations with ScrollTrigger
- Optimized bundle with code splitting
- Lazy loading and performance best practices

📱 **Fully Responsive**
- Mobile-first design
- Optimized for all screen sizes
- Beautiful mobile menu with animations

## Tech Stack

- **React 18** - UI library
- **TypeScript** - Type safety
- **Vite** - Build tool
- **Tailwind CSS** - Styling
- **GSAP** - Advanced animations
- **Lenis** - Smooth scrolling
- **i18next** - Internationalization
- **Lucide React** - Icons

## Getting Started

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
